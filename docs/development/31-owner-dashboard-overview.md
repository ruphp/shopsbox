# Кабинет владельца

Issue #80 расширяет обзор кабинета владельца.

## Что сделано

- В шапку кабинета добавлены быстрые переходы: обзор, товары, медиатека, публикация, настройки, заказы, preview.
- На странице `/owner` показаны:
  - статус магазина;
  - статус публикации;
  - публичный поддомен;
  - предупреждение о неподтвержденном телефоне;
  - предупреждение о неопубликованном магазине;
  - причина решения модерации, если она есть.
- Добавлены карточки быстрых действий для товаров, медиатеки, публикации, настроек, заказов и preview.

## Ограничения MVP

Сложные графики и реальные показатели заказов не добавлялись. Они относятся к будущему блоку статистики и отчетов.
