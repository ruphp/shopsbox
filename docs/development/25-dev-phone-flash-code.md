# Dev-подтверждение телефона

Issue #62 добавляет подтверждение телефона через одноразовый код без реального SMS-провайдера.

## Что сделано

- Вход по коду поддерживает два канала: email и телефон.
- По умолчанию выбран email.
- Телефон принимается в формате `+79XXXXXXXXX`.
- В dev/MVP код доставки показывается через flash-сообщение и дополнительно пишется в `var/auth-codes.log`.
- Контракт доставки кода остается в `Tenant/Application/Contracts`, реализация dev-доставки лежит в `Tenant/Infrastructure/Adapters`.
- До подтверждения активного неистекшего кода нельзя запросить новый код на тот же email или телефон.
- Для защиты MVP ограничены повторные запросы: не больше трех кодов за час на один канал и получателя.
- При успешном подтверждении сохраняются дата подтверждения, IP, user agent и provider=`flash_dev`.

## Что важно дальше

Когда появится production SMS, нужно заменить инфраструктурную реализацию доставки, не переписывая use case. Для первой регистрации отдельно надо связать подтвержденный канал с пользователем и не выдавать доступ к остальным сценариям, пока стартовый код не подтвержден.
