# Управление изображениями товара

Issue #61 добавляет жизненный цикл изображений товара.

## Что входит

- несколько изображений у товара;
- главное изображение;
- порядок изображений;
- soft-delete изображения;
- API для списка, выбора главного, изменения позиции и удаления.

## Витрина

Витрина берет первое доступное изображение по правилу:

1. главное изображение;
2. меньшая позиция.

Удаленные изображения не показываются.

## Медиатека

Медиатека не показывает удаленные изображения и считает usage только по активным изображениям.

## Проверки и тестовое покрытие

Новые тесты не добавлены по текущей договоренности.

Проверки:

- миграция;
- `php -l` новых/измененных классов;
- `lint:container`;
- `doctrine:schema:validate --skip-sync`;
- smoke-check карточки товара.
