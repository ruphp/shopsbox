# Тарифные лимиты файлов магазина

Issue #60 добавляет первый расчет лимитов файлов магазина.

## Текущий MVP

Лимит:

- 100 МБ на магазин;
- 100 файлов на магазин.

Расчет идет по `ProductImage`, потому что это текущая реализованная точка хранения пользовательских файлов. После появления `media_assets` расчет нужно перенести на медиатеку.

## Где видно

В `/owner/media` показывается:

- количество файлов;
- занятый размер;
- процент использования лимита;
- предупреждение при 80% и выше;
- сообщение о превышении лимита.

## Upload guard

`UploadProductImageUseCase` проверяет лимит перед записью файла через `FileStorage`.

Если жесткий лимит превышен, новая загрузка отклоняется. Уже опубликованная витрина не ломается.
