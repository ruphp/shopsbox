# Модераторская очередь

Issue #63 добавляет MVP-панель модератора для товаров и магазинов.

## Что сделано

- Добавлен модуль `Moderation` со слоями Application, Infrastructure и Presentation.
- Страница `/moderator` показывает:
  - товары со статусом `pending_review`;
  - магазины со статусом публикации `pending_review`.
- Для товаров доступны решения: одобрить, отклонить, заблокировать.
- Для магазинов доступны решения: одобрить, отклонить, заблокировать.
- При отклонении и блокировке причина обязательна.
- Причина решения сохраняется у товара или магазина.
- Владелец магазина видит причину решения на странице публикации магазина.

## Ограничения MVP

- Авторизация модераторов пока не реализована, она вынесена в отдельную задачу по админке платформы.
- История решений сейчас хранится как последнее решение в основной таблице. Полный журнал событий модерации нужен отдельной задачей.
- Причина попадания товара в очередь пока обобщенная: первая публикация или изменение карточки. Детализация по названию, описанию и изображению будет удобнее после отдельного события отправки на повторную модерацию.
