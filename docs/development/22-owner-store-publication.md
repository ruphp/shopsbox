# Экран публикации магазина

Issue #59 добавляет экран заявки на публикацию магазина на поддомене ShopsBox.

## Что входит

- маршрут `/owner/store/publication`;
- поля: ФИО, email, телефон, имя поддомена, согласие с ответственностью;
- статус публикации магазина;
- валидация поддомена;
- запрет системных имен;
- проверка уникальности поддомена;
- сохранение заявки в `stores`.

## Статусы

Минимальные статусы публикации:

- `draft`;
- `pending_review`;
- позже `published`;
- позже `blocked`.

После отправки формы магазин получает `pending_review`. Публичное открытие поддомена в этой задаче не включается.

## Проверки и тестовое покрытие

Новые тесты не добавлены по текущей договоренности.

Проверки:

- `doctrine:migrations:migrate --no-interaction`;
- `php -l` для новых классов;
- `lint:container`;
- `lint:twig templates/tenant`;
- smoke-check `/owner/store/publication` без сессии: редирект на вход.
