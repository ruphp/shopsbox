# Управление модераторами

Issue #67 добавляет MVP-основу админки модераторов.

## Что сделано

- Добавлена роль `platform_moderator`.
- Роль содержит только права модерации:
  - `platform.moderation.view`;
  - `platform.moderation.review`.
- Добавлена страница `/platform/moderators`.
- Администратор может назначить или снять роль модератора по email существующего пользователя.
- Добавлена таблица `moderator_action_logs`.
- Решения модератора по товарам и магазинам пишутся в журнал действий.

## Ограничения MVP

- Жесткая авторизация супер-админа и middleware доступа будут доделываться после полноценной платформенной админки.
- Распределение задач между модераторами пока не автоматизировано.
- Активность модератора сейчас хранится в журнале решений; отдельная аналитика активности нужна следующим шагом.

## Проверки и тестовое покрытие

Новые тесты не добавлены по текущей договоренности.

Проверки:

- миграция;
- `php -l` новых PHP-файлов;
- `lint:container`;
- `doctrine:schema:validate --skip-sync`;
- smoke-check `/platform/moderators`.
