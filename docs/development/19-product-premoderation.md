# Премодерация товаров

Issue #48 добавляет фундамент премодерации товаров на поддомене ShopsBox.

## Статусы

Публичная публикация товара отделена от рабочего статуса товара.

`status` отвечает за состояние товара в каталоге:

- `draft`;
- `active`;
- `archived`.

`publication_status` отвечает за публичную модерацию:

- `draft`;
- `pending_review`;
- `published`;
- `rejected`;
- `blocked`.

На витрине показываются только товары, у которых:

- `status = active`;
- `publication_status = published`.

## Когда нужна премодерация

Для магазина на поддомене ShopsBox первая публикация товара должна идти через `pending_review`.

Повторная премодерация нужна, если меняется важный публичный контент:

- публичное название;
- публичное описание;
- изображения.

Повторная премодерация не нужна при изменении:

- категории;
- SEO;
- характеристик;
- дополнительных полей;
- цены;
- остатка;
- артикула;
- сортировки;
- статуса наличия.

## Поля аудита

В `products` добавлены:

- `publication_submitted_by`;
- `publication_submitted_at`;
- `publication_reviewed_by`;
- `publication_reviewed_at`;
- `publication_review_reason`.

Полноценная история действий модерации может быть вынесена в отдельную таблицу позже.

## Проверки и тестовое покрытие

Новые unit-тесты не добавлены: добавлен фундамент модели и фильтрация витрины.

Проверки:

- `doctrine:migrations:migrate --no-interaction`;
- `lint:container`;
- `doctrine:schema:validate --skip-sync`;
- smoke-check активного опубликованного товара;
- smoke-check draft-товара.

При реализации use case нужны unit/application тесты переходов `publication_status`.
