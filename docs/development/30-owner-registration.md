# Регистрация владельца

Issue #83 добавляет первый сценарий регистрации владельца магазина.

## Что сделано

- Добавлена страница `/register`.
- Перед регистрацией требуется подтвержденный телефон из сценария `/auth/code?phone_required=1`.
- Владелец вводит ФИО, email, название магазина и короткое имя магазина.
- При регистрации создаются:
  - tenant;
  - первый store в статусе `draft`;
  - user владельца;
  - роль `store_owner` для этого магазина.
- После регистрации пользователь попадает в `/owner`.
- Публичный поддомен автоматически не открывается.
- В форме регистрации добавлено согласие с Пользовательским соглашением и Политикой конфиденциальности.

## Юридические страницы

В футер добавлены ссылки:

- `/privacy`;
- `/terms`;
- `/cookies`;
- `/payments`;
- `/contacts`.
