# Скрытый кабинет владельца магазина

Issue #46 добавляет скрытый каркас кабинета владельца.

## Маршруты

- `/owner` - обзор кабинета;
- `/owner/store/settings` - настройки магазина;
- `/auth/code` - вход по одноразовому коду.

Ссылки на кабинет не добавляются в публичную шапку, футер и sitemap.

## Индексация

Шаблоны кабинета используют `noindex, nofollow` через блок `meta_robots` в базовом layout.

## Роли

На ближайшую реализацию нужно разделять:

- владелец магазина;
- сотрудник магазина;
- модератор;
- суперадмин.

Сейчас кабинет использует существующую привязку владельца магазина через email и роль `store_owner`.

## Preview

Технический preview магазина доступен из кабинета. Публичная публикация поддомена должна быть отдельным действием после юридического подтверждения и модерационного решения.

## Проверки и тестовое покрытие

Новые тесты не добавлены: это первый каркас кабинета.

Проверки:

- `lint:container`;
- `lint:twig templates/tenant`;
- smoke-check `/owner` без сессии: редирект на вход;
- smoke-check `/owner/store/settings` без сессии: редирект на вход.
