# Уведомления модераторам

Issue #66 добавляет основу уведомлений о новых задачах модерации.

## Что сделано

- Добавлена таблица `moderation_notifications`.
- У уведомления есть статус:
  - `created`;
  - `sent`;
  - `error`;
  - `retry`.
- Добавлен contract `ModerationNotificationRepository`.
- Infrastructure-реализация создает уведомление только если для той же сущности уже нет активного уведомления со статусом `created` или `retry`.
- При отправке магазина на публикацию создается уведомление `store_publication`.

## Защита от лавины

На MVP уровне работает дедупликация по типу сущности, id сущности и активному статусу. Это не отправляет новое уведомление на каждое мелкое изменение, если задача уже ожидает обработки.

## Что дальше

- Подключить production dispatcher, который будет брать `created/retry` уведомления и отправлять email/SMS модераторам.
- Добавить уведомления для товаров, когда появится отдельный сценарий отправки товара на модерацию.
- Добавить группировку нескольких уведомлений в один дайджест для SMS.
