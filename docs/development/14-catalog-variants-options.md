# Расширенная модель каталога: вариации, опции и атрибуты

Issue #25 добавляет основу хранения вариантов товаров.

## Новые таблицы

- `product_option_groups` - группы опций внутри товара, например размер или цвет.
- `product_option_values` - значения опций, например `S`, `M`, `black`, `white`.
- `product_variants` - конкретные варианты товара с SKU и optional price adjustment.
- `product_variant_option_values` - связь варианта с выбранными значениями опций.
- `product_attributes` - простые характеристики товара, например материал, страна, гарантия.

## Граница модели

Product - базовая карточка товара.

Option group - измерение выбора внутри товара: цвет, размер, комплектация.

Option value - конкретное значение внутри группы.

Variant - продаваемая комбинация опций, у которой может быть свой SKU и корректировка цены.

Attribute - справочная характеристика товара, не обязательно влияющая на выбор варианта.

## Что не входит

- полноценный складской учет;
- скидки;
- корзина;
- SEO;
- image processing;
- UI управления вариациями.

## Проверки и тестовое покрытие

Новые unit-тесты не добавлены по текущей договоренности.

Что нужно покрыть позже:

- вариант не смешивает option values разных товаров;
- SKU уникален внутри товара;
- option group code уникален внутри товара;
- option value code уникален внутри группы;
- tenant/store boundary сохраняется во всех таблицах.
