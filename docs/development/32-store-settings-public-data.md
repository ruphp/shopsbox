# Публичные настройки магазина

Issue #82 расширяет настройки магазина в кабинете владельца.

## Что сделано

- В `stores` добавлены публичные данные магазина:
  - город;
  - адрес;
  - юридическое имя продавца;
  - ИНН;
  - юридический текст для витрины;
  - условия доставки;
  - условия оплаты.
- Поля протянуты через DTO, use case, Doctrine entity/repository и форму настроек.
- Валидация ИНН принимает 10 или 12 цифр.
- Внутренние технические настройки магазина остаются отдельно от публичных данных продавца.
