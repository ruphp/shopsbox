# Перенос проекта в папку shopsbox

Документ фиксирует физический перенос рабочей папки проекта и проверку нового workspace.

## Текущее состояние

Проект перенесен из старой папки:

```text
D:\codex\evirox.ru
```

Текущая рабочая папка:

```text
D:\codex\shopsbox
```

Git-репозитория пока нет, поэтому перенос папки не требовал сохранения `.git`-истории. Код приложения тоже еще не создан: перенесены документация, `Makefile`, `.github` templates и проектный контекст.

Проверка после переноса выполнена 2026-04-13 из `D:\codex\shopsbox`:

```text
make test
```

Результат: документационный каркас на месте, application tests пока не определены, потому что Symfony skeleton еще не создан.

## Что уже подготовлено

- Текущий бренд проекта в документации: ShopsBox.
- Рабочий домен: `shopsbox.ru`.
- Evirox оставлен как отложенное название для будущих идей.
- Поддомены для демо/пилота обновлены на `*.shopsbox.ru`.
- Makefile обновлен на ShopsBox.

## Как переносили

1. Закрыть процессы, которые держат файлы в `D:\codex\evirox.ru`.
2. Переместить папку:

```text
D:\codex\evirox.ru -> D:\codex\shopsbox
```

3. Открыть новый workspace уже из `D:\codex\shopsbox`.
4. Выполнить:

```text
make test
```

5. Проверить, что рабочие документы используют ShopsBox как текущий бренд. Упоминания Evirox остаются только как исторический путь переноса или отложенное название для будущих идей.

## Что не делать автоматически

- Не инициализировать git без отдельного решения.
- Не создавать Symfony skeleton до фиксации первого технического шага.
- Не удалять старую папку, пока не проверен новый workspace.
