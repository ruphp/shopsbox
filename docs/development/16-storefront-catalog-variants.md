# Витрина каталога с категориями и вариациями

Issue #27 расширяет публичную витрину магазина.

## Что показывает витрина

- список категорий магазина;
- страницу категории `/s/{storeSlug}/categories/{categorySlug}`;
- карточки активных товаров с изображениями;
- карточку товара с изображением, опциями, вариациями и характеристиками;
- только товары со статусом `active`.

`draft` и `archived` товары остаются в данных для админки и проверок, но публичные страницы их не отдают.

## Где лежит логика

- `Storefront/Application/UseCase` выбирает сценарий витрины;
- `Storefront/Application/Dto` хранит read model для Twig;
- `Storefront/Infrastructure/Persistence/Doctrine/Repository` читает данные из Doctrine;
- `templates/storefront` отвечает только за HTML-представление;
- стили витрины вынесены в `public/assets/storefront.css`.

## Что не входит

- корзина;
- checkout;
- расчет цены вариации;
- складские остатки;
- полноценный выбор вариации с пересчетом состояния через JavaScript.

## Проверки и тестовое покрытие

Новые unit-тесты не добавлены: задача меняет read model витрины и шаблоны, без нового доменного правила.

Проверки:

- `lint:container`;
- `doctrine:schema:validate --skip-sync`;
- проверка route для категорий;
- smoke-check активной категории;
- smoke-check активного товара;
- smoke-check, что draft-товар возвращает 404.
