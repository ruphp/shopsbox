# Кабинет владельца магазина: базовые настройки

Issue #23 добавляет первый экран кабинета владельца магазина.

## Сценарий

1. Владелец входит через `/auth/code`.
2. После подтверждения кода email хранится в session key `shopsbox_auth_email`.
3. Страница `/owner/store/settings` ищет активный store, связанный с пользователем через `user_roles`.
4. Владелец видит базовые настройки магазина.
5. Владелец может изменить название, публичное описание, контактный email, телефон, валюту и timezone.

## Граница MVP

- Slug и domain пока только показываются.
- Команда магазина, роли и сложный ACL не входят в эту задачу.
- Theme/page builder не входят в эту задачу.
- Настройки применяются только к store, который найден через owner email из сессии.

## Проверки и тестовое покрытие

Новые unit-тесты не добавлены по текущей договоренности: тесты разберем отдельно после основной мини-беты.

Что нужно покрыть позже:

- доступ без session redirect на `/auth/code`;
- владелец видит только свой store;
- успешное сохранение настроек;
- невалидный email;
- невалидная валюта;
- невалидный timezone.
