# Медиатека владельца магазина

Issue #58 добавляет первый экран медиатеки в скрытом кабинете владельца.

## Что входит

- маршрут `/owner/media`;
- список файлов магазина на базе `ProductImage`;
- фильтр по типу файла;
- отображение ключа, типа, размера, даты и места использования;
- подсчет занятого места по текущему фильтру;
- store boundary через текущего владельца магазина.

## Что не входит

- сложные превью;
- массовые операции;
- физическое удаление файлов;
- видеохостинг;
- полноценная таблица `media_assets`.

Следующий шаг - связать текущие `ProductImage` с будущей моделью `media_assets` и добавить безопасное удаление.

## Проверки и тестовое покрытие

Новые тесты не добавлены по текущей договоренности.

Проверки:

- `php -l` для новых классов;
- `lint:container`;
- `lint:twig templates/tenant`;
- smoke-check `/owner/media` без сессии: редирект на вход.
