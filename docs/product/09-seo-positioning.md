# SEO-позиционирование главной ShopsBox

Документ фиксирует текущий вывод по поисковому позиционированию главной страницы ShopsBox на основе первичных Wordstat-отчетов по России от 2026-04-18.

## Что было в отчете

В отчете есть левая и правая колонки Wordstat.

Левая колонка полезнее для SEO-ядра: там фразы, которые содержат исходный запрос или близкие формулировки. Для ShopsBox это основной источник выбора H1, title и смысловых блоков.

Правая колонка менее точная: там похожие и ассоциативные запросы. Ее можно использовать для идей, но нельзя брать как готовое SEO-ядро без ручной чистки. В ней встречаются нерелевантные фразы вроде `онлайн кинотеатр`, `сайт закупок официальный сайт`, `купи ру`, `озон каталог товаров`.

## Основные полезные ключи из левой колонки

Стартовое ядро:

- `создать интернет-магазин`;
- `создать интернет магазин`;
- `конструктор интернет-магазина`;
- `конструктор интернет магазина`;
- `готовый интернет-магазин`;
- `готовый интернет магазин`;
- `интернет-магазин под ключ`;
- `интернет магазин под ключ`;
- `купить готовый интернет магазин`;
- `готовый сайт интернет магазина`;
- `готовый интернет магазина цена`.

Корявые, но показательные хвосты вроде `готовый интернет магазина цена` не нужно использовать дословно в текстах. Они показывают намерение пользователя: человеку важна стоимость готового решения.

## Выбранный главный ключ

Главный ключ для главной страницы:

```text
создать интернет-магазин
```

Почему:

- фраза имеет лучшую точную частотность в отчете по России;
- она прямо описывает намерение пользователя;
- она понятнее для клиента, чем технические формулировки вроде `платформа интернет магазина`;
- она не сужает продукт до одного визуального редактора;
- вокруг нее можно естественно раскрыть ShopsBox как конструктор интернет-магазина, готовую ecommerce-основу, сопровождение, домен, SSL, бэкапы и перенос старого магазина.

## Вторичный ключ

Вторичный ключ:

```text
конструктор интернет-магазина
```

Его стоит использовать в title/meta и во втором смысловом блоке страницы.

Коммерческое уточнение:

```text
под ключ
```

Его стоит использовать в подзаголовке, meta description и блоках про сопровождение, но не делать главным H1.

Важно: ShopsBox не должен звучать как пустой drag-and-drop редактор. Правильный смысл: конструктор поверх готовой основы магазина. Клиент может настраивать блоки, секции и внешний вид, но каталог, админка, заказы, роли, домены, SSL, бэкапы и поддержка уже являются частью продукта.

## Рекомендованная структура главной

H1:

```text
Создать интернет-магазин
```

Title:

```text
Создать интернет-магазин | Конструктор интернет-магазина ShopsBox
```

Meta description:

```text
ShopsBox - интернет-магазин из коробки: конструктор страниц, каталог, админка, свой домен, SSL при необходимости, бэкапы, перенос старого магазина и сопровождение.
```

OG description:

```text
Создайте интернет-магазин быстрее: готовая основа магазина, каталог, админка, блоки страниц и техническое сопровождение в одной платформе.
```

Смысловые блоки:

- `Page builder для магазина`;
- `Конструктор интернет-магазина без сборки платформы с нуля`;
- `Свой домен, SSL, бэкапы и сопровождение`;
- `Поможем перенести старый интернет-магазин`;
- `Красивая витрина товаров` как отдельный сценарий магазина, а не главный смысл платформенной страницы.

## Текущие SEO-теги главной

Для `/` сейчас используются:

- `title`: `Создать интернет-магазин | Конструктор интернет-магазина ShopsBox`;
- `description`: `ShopsBox - интернет-магазин из коробки: конструктор страниц, каталог, админка, свой домен, SSL при необходимости, бэкапы, перенос старого магазина и сопровождение.`;
- `canonical`: `https://shopsbox.ru/`;
- `og:title`: совпадает с title;
- `og:description`: раскрывает готовую основу магазина, каталог, админку, блоки страниц и сопровождение;
- `twitter:card`: `summary_large_image`.

## Визуальная привязка к логотипу

Главная должна отталкиваться от логотипа ShopsBox:

- основной цвет интерфейса - синий/темно-синий;
- теплый желтый используется для акцентов, связанных с коробкой;
- коралловый используется точечно для активных элементов и эффекта конфетти;
- зеленую доминирующую палитру не использовать, потому что она спорит с логотипом.

Текущая CSS-палитра:

- `--ink: #10263d`;
- `--accent: #0077b6`;
- `--accent-dark: #06466d`;
- `--accent-warm: #f4b544`;
- `--accent-coral: #ff5a3c`.

## Что не выбирать главным ключом

Не выбирать главным H1:

- `конструктор интернет-магазина с готовым каркасом` - слово `каркас` звучит инженерно и немаркетингово;
- `создать интернет-магазин под ключ` - хороший коммерческий смысл, но по точной частотности сильно слабее, чем `создать интернет-магазин`;
- `платформа интернет магазина` - слишком сухо и B2B-технически;
- `готовый интернет магазин` - полезный дополнительный ключ, но слабее как главный призыв;
- `купить сайт`, `сделать сайт`, `заказать сайт` - слишком широкие и будут приводить нецелевую аудиторию;
- нерелевантные фразы из правой колонки Wordstat.
