# Доменная стратегия

## Бренд

Бренд текущего ecommerce-продукта: **ShopsBox**.

Основной домен: `shopsbox.ru` по проверке владельца проекта свободен на момент обсуждения.

Evirox оставляем для будущих идей или более широкой платформы.

## Почему ShopsBox

- понятнее для клиента: “готовый магазин в коробке”;
- легче связать с ecommerce, чем абстрактный tech-бренд;
- хорошо подходит для демо-магазинов и пакетного запуска;
- можно визуально обыграть `Box` как коробку/готовый комплект;
- хорошо раскладывается на продукты:
  - `ShopsBox Admin`;
  - `ShopsBox Store`;
  - `ShopsBox Cloud`;
  - `ShopsBox Own Infra`.

## Домены клиентов

У клиентов должно быть два сценария.

### Свой домен клиента

Клиент подключает собственный домен:

```text
client-shop.ru
www.client-shop.ru
```

Плюсы:

- клиент владеет своим адресом;
- лучше для бренда клиента;
- привычнее для покупателей.

### Поддомен ShopsBox

Если у клиента нет своего домена, даем поддомен:

```text
client.shopsbox.ru
```

Для демо и пилота можно использовать отдельные поддомены:

```text
client-demo.shopsbox.ru
client-pilot.shopsbox.ru
```

Они нужны для наглядного показа магазина до production-переноса или подключения домена клиента.

Варианты для админки:

```text
admin.shopsbox.ru
admin.client.shopsbox.ru
client.admin.shopsbox.ru
```

Предварительная рекомендация для MVP:

```text
client.shopsbox.ru         - публичная витрина клиента
admin.shopsbox.ru          - единая SaaS-админка
```

Почему так:

- проще объяснять;
- проще выпускать SSL;
- проще не путать витрину и админку;
- единая админка может переключаться между магазинами.

## Own Infra

Для Own Infra сценария клиент может использовать свой домен и свою инфраструктуру:

```text
shop.client-domain.ru
```

ShopsBox при этом остается control plane и управляет магазином через защищенный API/agent.

Сценарий “демо на поддомене ShopsBox -> production на хостинге клиента” описан в [Жизненном цикле магазина](05-store-lifecycle-demo-to-production.md).

## Что проверить перед запуском

- купить основной домен `shopsbox.ru`;
- проверить товарные знаки;
- проверить совпадения в App Store / Google Play;
- проверить GitHub organization/repository;
- определить wildcard SSL для `*.shopsbox.ru`;
- определить правила slug для клиентских поддоменов.
